; Keithley 2001 / 2001M / 2002 Bench Multimeter - TestController driver
;
; Coverage   Keithley 2001, 2001M and 2002 - three device definitions built
;            from one file, each with its own ranges and NPLC ceiling.
;            DC volts, AC volts, DC current, AC current, 2-wire and 4-wire
;            resistance, frequency and temperature, each on its own page with
;            ranging, integration time and the digital averaging filter. AC
;            adds detector and coupling, frequency a threshold source with the
;            trigger level as a percentage of range, temperature thermocouple
;            and RTD configuration. AutoZero and the display are global. One
;            logged channel per function.
;
; Verified   Co-authored with KungFuJosh and functionally validated against a
;            Keithley 2002 and a 2001M over GPIB before it was submitted
;            upstream; firmware revisions were not recorded and the 2001 takes
;            the 2001M's definition untested. No range or NPLC ceiling here
;            was read back from the instrument - those are the published
;            figures. HKJ took the file into TestController V3.41 (25 July
;            2026) and this copy is byte-identical to the one that release
;            installs, so it is deliberately unchanged and has not been
;            re-verified against hardware for this publication.
;            See instrument-notes.md beside this file.
;
; Revision   1.0
; Date       2026-07-25
; Author     KungFuJosh & Cyclotron
; Copyright  (c) 2026 KungFuJosh and Cyclotron
; License    MIT - see LICENSE
;
; TestController V3.41 and later already ships this definition as
; "Keithley 200X.txt". Both files claim the same #idString values and only one
; can win the match - keep one of the two in the Devices folder.
;
; Latest version: https://github.com/Cyclotronic/TC-Drivers
; TestController by HKJ: https://lygte-info.dk/project/TestControllerIntro%20UK.html
; Discussion: https://www.eevblog.com/forum/testgear/program-that-can-log-from-many-multimeters/

; =============================================================================

; =============================================================================
; 2. COMMUNICATION & INITIALIZATION
; =============================================================================

#initCmd *CLS;*RST;:SYST:PRES;SAMP:COUN 1;:TRIG:SOURCE IMM;:TRIG:SEQ:COUNT 1;:UNIT:TEMP C;:SENS:TEMP:TC:TYPE K;:SENS:TEMP:TC:RJUN:RSEL SIM;:SENS:TEMP:TC:RJUN:SIM 23;:SYST:AZER:STAT 1;:VOLT:DC:NPLC 10;:CURR:DC:NPLC 10;:RES:NPLC 10;:FRES:NPLC 10;:TEMP:NPLC 10;VOLT:DC:AVER:STAT 0;setVars;
#finalCmd *CLS;*RST;:SYST:PRES

; Setup internal variables for frequency range tracking
#scpiCmd setVars none
:setvar: freqVoltRange = 1.0
:setvar: freqCurrRange = 1.0

; =============================================================================
; 3. LOGGED VALUES & MODES
; =============================================================================

#value VoltageDC V SI8 DC_Voltage
#value CurrentDC A SI DC_Current
#value VoltageAC V SI8 AC_Voltage
#value CurrentAC A SI AC_Current
#value Resistance Ohm SI Two_Wire_Resistance,Four_Wire_Resistance
#value Frequency Hz SI Frequency
#value Period s D3 Period
#value Temperature °C D3 Temperature

#askValues FETC?
#askValuesReadFormat UXX
#readingDelay 5
#modeChangeDelay 10
#askMode FUNC?
#interfaceType DMM BMM
#interface readValue 0

#cmdModeLayout 4 2
#cmdMode DC_Voltage VOLT:DC *CLS;:FUNC "VOLT:DC";
#cmdMode AC_Voltage VOLT:AC *CLS;:FUNC "VOLT:AC";
#cmdMode Two_Wire_Resistance RES *CLS;:FUNC "RES";
#cmdMode Four_Wire_Resistance FRES *CLS;:FUNC "FRES";
#cmdMode DC_Current CURR *CLS;:FUNC "CURR:DC";
#cmdMode AC_Current CURR:AC *CLS;:FUNC "CURR:AC";
#cmdMode Frequency FREQ *CLS;:FUNC "FREQ";
#cmdMode Temperature TEMP *CLS;:FUNC "TEMP";

; =============================================================================
; 4. ACTIVE MODE DISPLAY & Mode Selector
; =============================================================================

#cmdSetup info Active_Mode
:read: FUNC?
:readmath: getElement("DC Voltage;AC Voltage;DC Current;AC Current;Two Wire Resistance;Four Wire Resistance;Frequency;Temperature",listIndex(unQuote(value),"VOLT:DC VOLT:AC CURR:DC CURR:AC RES FRES FREQ TEMP"," "),";")
:updatemodechange:
:tip: Shows current operating mode of the instrument.


#cmdSetup selector Mode_settings
:read: FUNC?
:readmath: unQuote(value)
:updatemodechange:
:tip: Active function selector mapping SCPI mode names to tab pages.
VOLT:DC DC_Voltage.
VOLT:AC AC_Voltage.
CURR:DC DC_Current.
CURR:AC AC_Current.
RES Two_Wire_Resistance.
FRES Four_Wire_Resistance.
FREQ Frequency.
TEMP Temperature.
