; Agilent / Keysight 33250A Arbitrary Waveform Generator - TestController driver
;
; Coverage   Agilent 33250A and Keysight 33250A, the 80 MHz function /
;            arbitrary waveform generator. One definition carries both device
;            names, split on the *IDN? manufacturer prefix.
;            Sine, square, ramp, pulse, noise, DC and arbitrary output;
;            amplitude in Vpp, Vrms or dBm or as high and low levels; output
;            load; AM, FM and FSK; sweep with a marker; triggered and gated
;            burst; the trigger subsystem and the trigger output; display
;            text, beeper, five stored states and the error queue.
;            Frequency, amplitude and offset are logged.
;
; Verified   Nothing here was re-measured for this publication - no 33250A was
;            to hand. The record is what the file documents from the
;            instrument it was written against: the pulse command headers
;            confirmed on firmware 2.04-1.01-2.00-03-2, and the arb name
;            substitution seen on the wire. It has been in service over GPIB,
;            and HKJ took it into TestController V3.48 (12 August 2026) with
;            no changes asked for. The display-text write is marked untested
;            in the body. See instrument-notes.md beside this file.
;
; Revision   1.0
; Date       2026-07-30
; Author     Cyclotron
; License    MIT - see LICENSE
;
; TestController V3.48 and later ships this driver as "Agilent 33250a.txt".
; Two files claiming the same #idString cannot both win the match, so move the
; shipped one out of the Devices folder if you install this copy.
;
; Latest version: https://github.com/Cyclotronic/TC-Drivers

; ----------------------------------------------------------------------
; Connect / disconnect
;
; VOLT:UNIT is forced to VPP at connect because VOLT? returns whatever
; unit the instrument happens to be in, and every amplitude limit in
; this file assumes Vpp. The unit is still selectable on the System
; page if you need Vrms or dBm.
;
; SYST:REM is deliberately NOT sent: on the 33250A the remote/local
; commands apply to RS-232 only and will error over GPIB. If you use
; the serial port and want front-panel lockout, switch to
; "#driver SCPIx" and use the conditional form:
;   #scpiCmd MyRemote #pgm#
;   if (portType!="GPIB")
;    deviceWrite(handle,"SYST:REM;");
;   endif;
; ----------------------------------------------------------------------

#initCmd *CLS;VOLT:UNIT VPP

; Leaves the output off and the error queue clear on disconnect.
#finalCmd OUTP OFF;*CLS

; "Outputs off" button.
#outputOff OUTP OFF

; ARB SELECTION - THE UNDERSCORE PROBLEM
;
; TC replaces every underscore with a space before the text reaches the
; instrument, and it does this in BOTH the combobox parameter column
; and the :write: tag of a button. Confirmed on the wire:
;   A33250: Tx <FUNC:USER EXP RISE>   ... 45 58 50 20 52 49 53 45
; So neither a combobox entry "Exp_Rise EXP_RISE" nor a button with
; ":write: FUNC:USER EXP_RISE" can ever select the three built-in arbs
; whose names contain an underscore. SINC and CARDIAC work only because
; they have no underscore to lose.
;
; The way out is to stop putting the name in the config file at all.
; A text control sends what YOU type at runtime, which is not subject to
; the substitution. Type the name exactly as DATA:CAT? reports it:
;   EXP_RISE  EXP_FALL  NEG_RAMP  SINC  CARDIAC
; This also handles arbs you have downloaded yourself, which a fixed
; list never could.
;
; If TC turns out to support :writemath: as the counterpart to
; :readmath:, the nicer combobox below becomes possible - it puts the
; underscore back after TC has removed it. You can tell in one run: the
; debug log already prints "Rx after :readmath:" lines, so a working
; write tag should produce a matching "Tx after :writemath:" line.
; No such line means the tag was ignored.
;
; #cmdSetup combobox Arb_Shape Wave
; :read: FUNC:USER?
; :readmath: replace(value,"_"," ")
; :write: FUNC:USER
; :writemath: replace(value," ","_")
; :string:
; :enable: inList(Main.Waveform,"USER")
; Exp_Rise EXP_RISE
; Exp_Fall EXP_FALL
; Neg_Ramp NEG_RAMP
; Sinc SINC
; Cardiac CARDIAC

#cmdSetup text Arb_Shape Wave
:read: FUNC:USER?
:write: FUNC:USER
:string:
:enable: inList(Main.Waveform,"USER")
:tip: Type the name exactly as shown in Arb_Catalog below - EXP_RISE, EXP_FALL, NEG_RAMP, SINC, CARDIAC, or the name of an arb you have downloaded. Do not quote it.
16

; The only two built-ins that survive the underscore substitution, kept
