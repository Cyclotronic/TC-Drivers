; HP / Agilent 6060B 300 W DC Electronic Load - TestController driver
;
; Coverage   HP / Agilent 6060B.
;            Constant current (6 A / 60 A ranges), constant voltage, and
;            constant resistance (low / middle / high ranges); continuous,
;            pulsed and toggled transient operation; software over-current
;            protection and input short simulation. Mode buttons switch a
;            single per-mode settings view, with the active mode and Input on
;            top and the transient and protection settings at the bottom of
;            every view.
;
; Verified   Against a 6060B (firmware A.02.01) over GPIB - every command
;            exercised on the instrument, every per-range limit read back from
;            the hardware rather than the datasheet. Behaviour a user needs:
;            MODE:CURR / :VOLT / :RES only (the "MODE CURR" space form is
;            accepted then ignored); both slew rates snap to 12 discrete steps
;            and clamp out-of-range values silently; constant resistance has no
;            slew command and borrows the CV slew (low range) or CC slew (mid
;            and high); an over-current trip clears with INPut:PROTection:CLEar,
;            not CURR:PROT:CLE; the protection-status decode is unestablished so
;            the indicator shows only healthy vs fault. Input current draw,
;            short simulation and an over-current trip need a source on the
;            input and were not exercised. See instrument-notes.md beside this
;            file.
;
; Revision   1.1
; Date       2026-08-29
; Author     Cyclotron
; License    MIT - see LICENSE
;
; Latest version: https://github.com/Cyclotronic/TC-Drivers
; TestController by HKJ: https://lygte-info.dk/project/TestControllerIntro%20UK.html
; Discussion: https://www.eevblog.com/forum/testgear/program-that-can-log-from-many-multimeters/

; =========================================================
; Constant Current  (MODE:CURR)
; =========================================================
; The Range radio picks the 6 A / 60 A range; each range-dependent field then
; follows through its own nested selector so its leaf pages carry literal limits
; and exactly one control each.
#cmdSetup radio CC_Range CC
:read: CURR:RANG?
:readmath: (0+value)>10?"High":"Low"
:write: CURR:RANG (getElement("6 60",listIndex(value,"Low High"," ")," "))
:string:
:updatemodechange:
:update: CC_Current_sel CC_Transient_sel CC_Triggered_sel
:updatedelayed: 0.3
:tip: The 6 A range gives finer resolution; the 60 A range covers full current. The current fields below re-scale when this changes.
Low Low
High High

#cmdSetup indicator Protection_Status Protection
:read: STAT:QUES:COND?
:updatemodechange:
:updatealloff:
:tip: Lights red on any questionable-status condition - over-current, over-voltage, over-temperature or reverse voltage. The raw status code is shown. The per-bit decode has not been confirmed on this instrument, so no single condition is named. The input stays latched off until Clear Protection is pressed.
Normal int(value)==0 green
Fault int(value)!=0 red

#cmdSetup button Clear_Protection Protection
:write: INP:PROT:CLE
:update: Protection_Status
:updatedelayed: 0.3
:tip: Clears a latched protection shutdown. The input stays off until this is pressed and then switched back on.
